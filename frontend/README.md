# T1 frontend

Solid 2 bare template, with the Glorix bookings listing.

Run `pnpm dev --port 3100 --strictPort` to develop, `pnpm typecheck` to check TypeScript, and `pnpm build` for static production files in `dist/client`.

See [the experiment guide](../README.md) for the single-store data layer, source files, and backend commands.
